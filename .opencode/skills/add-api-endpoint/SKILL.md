# Добавление нового API-эндпоинта

## Когда использовать
Используй этот навык, когда пользователь просит:
- «Добавь API-эндпоинт»
- «Создай новый роут»
- «Сделай endpoint для …»

## Пошаговая инструкция
1. **Определи модель запроса.** Если эндпоинт принимает тело, создай Pydantic-модель в `app/main.py` (или импортируй существующую).
2. **Создай функцию-обработчик.** Добавь в `app/main.py` функцию с декоратором `@app.post(...)` или `@app.get(...)`. Используй `async def`.
3. **Реализуй логику.** Вызови нужные сервисы из `app/rag.py` или `app/providers.py`. Не пиши логику прямо в роуте, если её можно вынести в сервис.
4. **Верни ответ.** Верни `dict`, FastAPI сам преобразует его в JSON.
5. **Проверь синтаксис.** Выполни `python -m py_compile app/main.py`, чтобы убедиться, что файл компилируется.

## Правила проекта
- Все комментарии, docstrings и user-facing строки — на русском.
- Используй `type hints` для аргументов и возвращаемых значений.
- Не изменяй файлы в папках `data/` и `chroma_db/` без явной просьбы.

## Пример
```python
from pydantic import BaseModel

class NewQuery(BaseModel):
    text: str

@app.post("/api/new-feature")
async def new_feature(query: NewQuery) -> dict:
    """Краткое описание, что делает эндпоинт."""
    # Твоя логика здесь
    result = query.text.upper()
    return {"status": "ok", "result": result}
